# API Python — Sistema de Vendas

Projeto em Python para aprender a consumir uma API REST, trabalhar com JSON e preparar dados para uma futura integração com MySQL.

## Objetivos

- Fazer requisições HTTP com Python
- Consumir dados de uma API pública
- Trabalhar com JSON
- Tratar erros de requisição
- Pesquisar e filtrar dados
- Salvar dados localmente

## Tecnologias

- Python 3
- Requests
- API REST
- JSON
- Git e GitHub

## Próximos passos

1. Consumir produtos de uma API pública
2. Criar consultas e filtros
3. Salvar dados em JSON
4. Integrar os dados com o banco MySQL do projeto `database-sistema-vendas`
5. Criar uma API própria com FastAPI

> Projeto desenvolvido para estudo e portfólio, com foco em integração entre sistemas.
